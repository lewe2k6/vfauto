# Pin & Nhiệt Độ (TrollStore iOS 16.3.1 - iPhone 8)

Gói công cụ ngụy trang kiểm tra Pin & Nhiệt độ tích hợp lõi ngầm `pind` chạy quyền TrollStore:
- Tự động đọc giá tiền đơn **Green Food**: Đạt ngưỡng tối thiểu (mặc định `25.000đ`) tự bấm **Nhận chuyến**, thấp hơn tự bấm **[X]**.
- Các chuyến còn lại (**Bike / Express**): Tự động bấm **Nhận chuyến**.
- Mở bảng tinh chỉnh ẩn: **Nhấn giữ 2 giây** vào tiêu đề **`Trạng thái Pin`**.
- Hoạt động khi **Chế độ nhà phát triển = TẮT**, không can thiệp file của Xanh SM Bác Tài.

## Cách Lấy File `.tipa` Tự Động Trên GitHub
1. Đẩy thư mục này lên 1 kho chứa (Repository) GitHub của bạn (chạy file `push_to_github.ps1` hoặc gõ lệnh Git).
2. Vào tab **Actions** trên GitHub đợi ~1.5 phút cho tích xanh.
3. Mở Safari trên iPhone 8 vào mục **Releases** của repo -> Tải **`PinNhietDo_TS.tipa`** -> Chia sẻ sang **TrollStore** -> **Install**.
